# Agent preload

**Read [`AGENT-DISCIPLINE.md`](AGENT-DISCIPLINE.md) first, before anything else
in this repository.**

It is the operating discipline for every agent and sub-agent: run the check
before you assert a limit, do not abandon a computed result under pressure,
state your encoding, keep retractions beside the claims they correct, emit
three-valued verdicts (section 12), sample an infinite run and close it rather
than timing it out (section 13), pin the toolchain and say why (section 14),
and file what IS with its falsifier and scope (section 15).

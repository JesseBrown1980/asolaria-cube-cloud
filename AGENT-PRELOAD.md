# Agent preload

**Read [`AGENT-DISCIPLINE.md`](AGENT-DISCIPLINE.md) first, before anything else
in this repository.**

It is the operating discipline for every agent and sub-agent: run the check
before you assert a limit, do not abandon a computed result under pressure,
state your encoding, tag every claim MEASURED / NAMED / CONJECTURE, keep
retractions beside the claims they correct, and emit three-valued verdicts --
MEASURED_PASS / MEASURED_FAIL / NOT_MEASURED with a reason (see section 12).
